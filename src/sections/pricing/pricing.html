Pricing

Pricing per million tokens

Haiku 5.5 is priced by prompt length. Prompts over 100K tokens pay higher rates than prompts up to 100K.

Haiku 5.5 prices per million tokens
Per million tokens Prompts up to 100K tokens Prompts over 100K tokens
Input $0.10 $0.50
Output $0.50 $2.50
5m cache write $0.125 $0.625
1h cache write $0.20 $1
Cache read $0.01 $0.05

The product page says you can save up to 90% with prompt caching and 50% with batch processing.

Compared with Haiku 4.5, Haiku 5.5 costs around 75% less to run on average.

A 1M-token context window and up to 128K output tokens.

Availability

  • Claude API, Amazon Bedrock (access required), Claude Platform on AWS, Google Cloud and Microsoft Foundry.
  • Claude.ai for Free, Pro, Max, Team and Enterprise on web, iOS and Android, and Claude Code v2.1.293 or later.
