## How to use it in Suno

**Option 1: let Suno write the music.**
1. Open Create, switch to Custom mode, and paste the Title, Style, Exclude Styles and Lyrics above.
2. Generate a few versions and keep the best one.

**Option 2: keep this song's melody and structure.**
1. Use Suno's audio upload and "Cover" feature with `preview.mp3` (it includes a synth voice singing the vocal melody).
2. Use the same lyrics and style.
3. If you'd rather Suno invent the vocal melody over this backing track, upload `instrumental.mp3` instead.

These feature names change between Suno versions, so check what your plan and version currently offer.

## Tips

- **Length:** Suno decides the final length. These lyrics are sized for about 2:00 at 168 BPM, and the `[End]` tag helps it stop, but it can still run long, so trim the ending if needed.
- **Tags sung out loud:** if Suno sings a tag like "gang vocals", delete the words after the colon, for example `[Post-Chorus: gang vocals]` → `[Post-Chorus]`.
- **Different singer:** swap "powerful female vocals" for "powerful male vocals" in the Style box.
- **Roblox:** the lyrics are clean (no swearing or gore), so they have a better chance of passing Roblox audio moderation.
- **Rights:** check that your Suno plan allows commercial use before you put the song in a game that earns Robux. Free-plan songs generally can't be used commercially.
