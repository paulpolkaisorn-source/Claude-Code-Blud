## Tips

- **Uploading audio:** if you upload audio for a Cover, use `instrumental.mp3`. `preview.mp3` has a synth "voice" playing the melody, which could push Suno toward adding vocals.
- **Length:** Suno picks the final length and can run past 2:00, so trim the ending if needed.
- **Rights:** check that your Suno plan allows commercial use before you put the song in a game that earns Robux. Free-plan songs generally can't be used commercially.
