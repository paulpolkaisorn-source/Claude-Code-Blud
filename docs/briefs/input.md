GOAL: desktop + mobile input writing player.input (makeInput shape). API: ARCHITECTURE.md "input".
FILES: src/input/input.js, src/input/touch.js, tests/browser/input.html.
DESKTOP: WASD/arrows move (normalized; screen-up = -z, right = +x). Mouse: aim = normalize(screenToGround(cursor) - player pos); aimLen = clamp(dist/attack.range,0,1) (super uses super.range when superAiming). LMB → fire edge (manual aim). RMB or E → superFire edge (block contextmenu). Q/Space → autoFire edge; F → autoSuper edge. aiming=true while cursor over canvas. Esc/P → bus.emit(EV.UI_PAUSE). Keys released on blur.
MOBILE (mobile flag): inject own <style> + DOM into root. Left: floating move joystick (spawns at touch point, clamp radius). Right: attack joystick — drag past deadzone → aiming with drag direction, release → fire edge using that aim; quick tap (<220ms, tiny drag) → autoFire edge. Super button above it: same drag/tap → superFire / autoSuper; glow + pulse when setSuperReady(true), dimmed otherwise. Pointer events + setPointerCapture, multi-touch, touch-action:none, env(safe-area-inset-*) margins, fits 390×844, big thumb-friendly sizes, chunky cartoon style.
update(player): writes moveX/moveZ/aim fields, ORs edges (game clears them). setEnabled(false) zeroes move & ignores input. setTouchVisible toggles overlay. dispose removes listeners/DOM.
TESTS (browser, desktop + --mobile): keys → move vector; mouse click → fire edge + aim toward cursor (stub screenToGround); Esc → UI_PAUSE; pointer drags on joysticks → move, aimed fire, tap autoFire, super; overlay inside viewport.
