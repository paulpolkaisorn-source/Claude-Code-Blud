R Map

A blocky Roblox map shaped like the letter R: green floor, grey walls with a red strap along the bottom, running along every edge of the shape, including around the hole in the R's loop. Below: a 3D preview drawn from the script, how to build it in Studio, and the full script.

      Build it in Roblox Studio

      1. Keep it in your place (recommended)

        Open View → Command Bar, paste the whole script and press Enter. The map is saved with your place as the model RMap.

      2. Or build it when the server starts

        Add a Script to ServerScriptService and paste the script into it. The map is rebuilt every time a server starts.

      3. Change the shape

        Edit the SHAPE art at the top: # is floor, . is empty. Walls follow the new outline automatically. Running it again replaces the old map.

      Heads up: by default the script deletes the template Baseplate and SpawnLocation in Workspace, because the baseplate would fill the R's hole. Set REMOVE_TEMPLATE_PARTS = false to keep them.
