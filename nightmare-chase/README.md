# Nightmare Chase Theme

An original chase theme for a Roblox horror game. It has the same feel as the reference track (`LAYER_4_ENNARD`), but the key, chord progressions and melodies are all new.

| | |
|---|---|
| **Tempo** | 160 BPM |
| **Time signature** | 4/4 |
| **Key** | D minor (Phrygian ♭2 grind + harmonic-minor V) |
| **Length** | 80 bars = **exactly 2:00**, loops seamlessly (bar 80 → bar 1) |
| **Files** | `nightmare_chase_theme.mid` (6 tracks), `preview.mp3` (rough synth render) |

## What I kept from the reference vs. what's new

Analysis of the reference:
- 160 BPM, 4/4, 2:01
- Tonal centre C minor, with a constant C–D♭ semitone "grind"
- A i ↔ ♭II (C ↔ D♭) pedal for the first ~1:13
- A harmonic-minor climax from 1:13 onward: Cm – A♭ – G, with a high lead around C6

**Kept (the vibe):** same tempo, same 2:00 length, a minor key with the ♭2 semitone horror grind, a harmonic-minor dominant for the tension, and the energy peaking in the last third.

**New (its own identity):**
- **Key:** D minor instead of C minor.
- **Hook:** a 3+3+2 ("tresillo") rhythm used in the ostinato and the melodies, where the reference uses straight grinding 8ths.
- **Chase A progression:** a chromatic "lament" bass that falls D – C♯ – C – B – B♭, then the Neapolitan E♭ → A.
- **Chase B progression:** includes the tritone chord A♭ major against the D minor tonality.
- **Climax progression:** i – iv – ♭II – V / i – VI – vii°7 – V (Dm Gm E♭ A / Dm B♭ C♯dim7 A7♭9).
- **Breakdown:** a quiet "Hide" section with a music box before the climax.
- **Bass:** a heartbeat pattern in the intro and outro.
- **Melodies:** every melody is written from scratch.

## MIDI tracks

| Track | Channel | GM sound (suggested) | Swap it for |
|---|---|---|---|
| Lead Melody | 1 | Saw Lead | distorted synth lead, detuned supersaw, or screaming strings |
| Lead Harmony | 2 | Saw Lead | same sound as the lead, slightly quieter |
| Music Box | 3 | Music Box | music box / celesta + big reverb |
| Ostinato Hook | 4 | Square Lead | plucky synth, detuned piano, or staccato strings |
| Chords | 5 | String Ensemble | dark pad or low strings |
| Bass | 6 | Synth Bass | distorted reese / 808 |

There are no drums in the MIDI (only chords and melody were asked for). A four-on-the-floor kick with a snare on 2 and 4, plus 16th hats in Chase B and the Climax, fits the bass patterns.

Chord names are stored as text events on the Chords track, and section names are stored as markers, so they show up in most DAWs.

## Rebuild / tweak

All the notes live in `song.py` (easy-to-edit lists). After changing them:

```bash
pip install mido numpy scipy soundfile imageio-ffmpeg
python song.py            # -> nightmare_chase_theme.mid
python render_preview.py  # -> preview.mp3 (rough numpy synths, reverb tail wraps to the start for looping)
```

## Using it in Roblox

Export your final mix as `.ogg` or `.mp3`, upload it (Creator Hub → Audio), put it in a `Sound`, and set `Looped = true`. The song is exactly 80 bars, so it loops on the beat. OGG loops cleaner than MP3, because MP3 encoders add a tiny bit of silence at the start.
