# 007n7: manual in-game checks

Setup: play as 007n7 against a bot killer. Hotbar: 2 = Clone, 3 = c00lgui, 4 = Inject.

## DEX (passive)
- [ ] A particle column and ring mark one survivor spawn. Only you see it; check from a second client if you can.
- [ ] The marked spawn is the one furthest from you. Walk across the map and it switches.
- [ ] The c00lgui slot shows the distance to the marked spawn (→Nm).

## Inject (slot 4)
- [ ] Each press cycles Aimless → Pathfind → Cursor. A flash message names the mode, and the slot suffix shows it.
- [ ] There is no cooldown.
- [ ] A clone keeps the mode it spawned with, even if you switch afterwards.

## Clone (slot 2)
- [ ] Press it. A clone named and skinned like you appears with your current HP.
- [ ] The clone runs forward about 0.5 s in the direction you face.
- [ ] You get Invisibility IV and Undetectable for 5 s.
- [ ] For 3 s all your abilities are refused, but no HELPLESS shows on the HUD (the HUD must hide statuses with data.hidden).
- [ ] Aimless: the clone wanders and changes direction every 2–4 s.
- [ ] Pathfind: the clone walks to the DEX spawn and stops there.
- [ ] Cursor: the clone runs straight where you were looking and stops at the first wall.
- [ ] The clone has a white outline/marker that only you see.
- [ ] The killer can hit the clone. It takes damage and disappears when it dies.
- [ ] The clone gets no speed boost when hit.
- [ ] The clone vanishes after 10 s, even if you were eliminated in the meantime.
- [ ] Cooldown is 27 s.

## c00lgui (slot 3)
- [ ] Press it. A 5.5 s channel bar appears and you move at about 15% speed.
- [ ] At the end you teleport to the DEX spawn.
- [ ] Taking damage during the first 5 s cancels it.
- [ ] Taking damage in the last 0.5 s does not cancel it.
- [ ] Sneaking at a generator in range cancels it, and you start repairing.
- [ ] A stun cancels it.
- [ ] Cooldown is 50 s.
