Haiku 5.5 is a strong computer use agent for repetitive tasks like form filling, data entry, and moving information between apps.

It reliably handles quick and repetitive workloads, like summaries, compactions, database queries, and classification requests.

import Anthropic from "@anthropic-ai/sdk";
const client = new Anthropic();
await client.messages
  .stream({
    model: "claude-haiku-5-5", max_tokens: 1024,
    output_config: { effort: "low" },
    messages: [{ role: "user", content: "Hello" }],
  })
  .on("text", (t) => process.stdout.write(t));
