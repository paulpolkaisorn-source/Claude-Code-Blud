# Tank Blitz

A turn-based artillery game (Tank Stars style) in a single file. Open `index.html` in a browser.

- Modes: you vs CPU (3 difficulty levels), 2 players on one screen, CPU vs CPU
- Destructible terrain, wind, 4 weapons (Shell, Heavy, Triple, Sniper), fuel-limited driving, fall damage
- Controls: `A`/`D` drive, `←`/`→` aim, `↑`/`↓` power, `Shift` fine-tune, `1`-`4` weapon, `Space` fire, `M` mute. On-screen buttons for touch.
